# Zero-Cost Policy (سياسة التكلفة الصفرية)

## الحالة الحالية

**Paid execution (التشغيل المدفوع): DISABLED (معطل).**

النسخة الحالية من Agent IA Factory (مصنع وكلاء الذكاء الاصطناعي) يجب أن تعمل دون أي مصروف إضافي إلزامي.

## القواعد

1. لا Credit Card Requirement (اشتراط بطاقة بنكية) لأي مكوّن أساسي.
2. لا Auto Upgrade to Paid (ترقية تلقائية إلى مدفوع).
3. لا Pay-as-you-go (دفع حسب الاستعمال) مفعل افتراضياً.
4. كل Provider Adapter (موصل مزود) له `cost_mode` واضح.
5. إذا كانت تكلفة تنفيذ غير معروفة، Fail Closed (يفشل بأمان) ولا ينفذ.
6. إذا انتهت Free Quota (الحصة المجانية)، يتوقف المسار أو ينتقل لمسار مجاني آخر؛ لا يشتري سعة إضافية.
7. الاشتراكات الموجودة مسبقاً عند صاحب المشروع، مثل GitHub Pro (غيت هب برو) وChatGPT Pro (شات جي بي تي برو)، تُعامل كموارد تطوير موجودة وليست متطلبات تشغيل للمنتج.
8. OpenAI API (واجهة أوبن أي آي) وأي API مدفوعة ليست جزءاً إلزامياً من النسخة المجانية.

## Cost Modes (أنماط التكلفة)

- `local_free` — مجاني ومحلي.
- `oss_self_hosted` — مفتوح المصدر ويحتاج فقط موارد متاحة للمستخدم.
- `free_tier_hard_stop` — حصة مجانية تتوقف دون فاتورة.
- `existing_subscription_dev_only` — اشتراك موجود يستعمل للتطوير فقط.
- `paid_optional_disabled` — مدفوع اختياري ومعطل حالياً.
- `rejected_paid_required` — مرفوض لأنه يتطلب الدفع.

## Cost Governor (حاكم التكلفة)

في Phase 1 (المرحلة الأولى) يجب أن توجد قيمة مركزية:

```text
MAX_MONETARY_SPEND_USD = 0
```

أي تنفيذ يمكن أن يؤدي إلى مبلغ أكبر من صفر يجب أن يُرفض قبل الإرسال إلى المزود.

## الترقية مستقبلاً

إذا قرر صاحب المشروع مستقبلاً السماح بميزانية، يتم ذلك عبر Policy Change (تغيير سياسة) صريح ومراجع، ولا يكفي إضافة API Key (مفتاح واجهة برمجية) لتفعيل الإنفاق تلقائياً.
