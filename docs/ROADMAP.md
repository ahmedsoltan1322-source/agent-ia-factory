# Roadmap (خارطة الطريق)

## Phase 0 — Foundation (المرحلة صفر — الأساس)

الهدف: تثبيت القواعد قبل البرمجة.

المخرجات:
- Architecture (المعمارية).
- Agent Specification (مواصفات الوكيل).
- Security Model (نموذج الأمان).
- Zero-Cost Policy (سياسة التكلفة الصفرية).
- Phone-Only Mode (وضع الهاتف فقط).
- OSS Catalog (دليل المصادر المفتوحة).
- Acceptance Criteria (معايير القبول).

## Phase 1 — Single Agent Core (المرحلة الأولى — نواة وكيل واحد)

الهدف: أول Agent (وكيل) حقيقي يعمل من الهاتف.

المخرجات:
- Web App/PWA (تطبيق ويب قابل للتثبيت).
- Agent Registry (سجل الوكلاء).
- Agent Spec Validation (التحقق من مواصفات الوكيل).
- Runtime Adapter واحد.
- Model Router أولي.
- Tool Registry (سجل الأدوات).
- Human Approval (موافقة بشرية).
- Run Log (سجل التشغيل).
- Zero-Cost Enforcement (فرض التكلفة الصفرية).

معيار الخروج: إنشاء Agent من الهاتف وتشغيله ومراجعة النتيجة بتكلفة إلزامية 0$.

## Phase 2 — Memory & Knowledge (المرحلة الثانية — الذاكرة والمعرفة)

- Session Memory (ذاكرة الجلسة).
- Long-Term Memory (ذاكرة طويلة الأمد).
- Knowledge Files (ملفات المعرفة).
- Search/RAG (البحث والاسترجاع المعرفي).
- Export/Delete Memory (تصدير/حذف الذاكرة).

## Phase 3 — Tools & MCP (المرحلة الثالثة — الأدوات وMCP)

- Tool SDK (حزمة تطوير الأدوات).
- MCP Client (عميل MCP).
- MCP Security Gate (بوابة أمان MCP).
- Permission Scopes (نطاقات الصلاحيات).
- Tool Sandboxing (عزل الأدوات).

## Phase 4 — Workflows & Multi-Agent (المرحلة الرابعة — سير العمل وتعدد الوكلاء)

- Sequential/Parallel Workflows (تسلسلي/متوازي).
- Supervisor Agent (وكيل مشرف).
- Worker Agents (وكلاء عاملون).
- Shared Team Memory (ذاكرة فريق مشتركة).
- Handoffs (تسليم المهمة بين الوكلاء).

## Phase 5 — Agent Factory (المرحلة الخامسة — المصنع الحقيقي)

- Natural-Language Agent Creation (إنشاء وكيل بوصف لغوي).
- Factory Architect Agent (وكيل مهندس المصنع).
- Tool Builder Agent (وكيل بناء الأدوات).
- Test Builder Agent (وكيل بناء الاختبارات).
- Auto-Repair Loop (حلقة إصلاح تلقائي).

## Phase 6 — OSS Harvester (المرحلة السادسة — جامع المصادر المفتوحة)

- GitHub Discovery (اكتشاف GitHub).
- License Scoring (تقييم الترخيص).
- Maintenance Scoring (تقييم الصيانة).
- Security Scanning (الفحص الأمني).
- Sandbox Benchmark (اختبار الأداء المعزول).
- USE / ADAPT / STUDY / WATCH / REJECT decisions.

## Phase 7 — Browser & Computer Agents (المرحلة السابعة — وكلاء المتصفح والحاسوب)

- Browser Automation (أتمتة المتصفح).
- Safe Form Filling (ملء النماذج بأمان).
- Downloads/Uploads (تنزيل/رفع الملفات).
- Screenshot/Visual Verification (التحقق البصري).
- Strict Approval Gates (بوابات موافقة صارمة).

## Phase 8 — Evaluation Arena (المرحلة الثامنة — ساحة التقييم)

- Agent Benchmarks (معايير أداء الوكلاء).
- Regression Suites (اختبارات عدم التراجع).
- Reliability Score (درجة الاعتمادية).
- Security Score (درجة الأمان).
- Cost Score (درجة التكلفة).
- Comparative Arena (ساحة مقارنة).

## Phase 9 — Deployment & Scale (المرحلة التاسعة — النشر والتوسع)

- Multi-tenant-ready Architecture (معمارية جاهزة لتعدد المستخدمين) دون إدخال قيود ترخيصية غير مناسبة.
- Queues (طوابير).
- Durable Jobs (مهام قابلة للاستئناف).
- Rate Limits (حدود الاستخدام).
- Backup/Restore (نسخ احتياطي/استعادة).
- Self-host Options (خيارات استضافة ذاتية).

## Phase 10 — Ecosystem (المرحلة العاشرة — النظام البيئي)

- Agent Templates (قوالب وكلاء).
- Tool Marketplace Architecture (معمارية سوق أدوات) مع فحص أمني.
- Import/Export (استيراد/تصدير).
- Community OSS Catalog (دليل مجتمعي للمصادر المفتوحة).
- Plugin/Adapter SDK (حزمة تطوير الموصلات).
