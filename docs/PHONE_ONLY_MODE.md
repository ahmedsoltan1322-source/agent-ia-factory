# Phone-Only Mode (وضع الهاتف فقط)

## الهدف

يجب أن يستطيع صاحب المشروع استخدام Agent IA Factory (مصنع وكلاء الذكاء الاصطناعي) من هاتف iPhone/Android دون امتلاك حاسوب.

## واجهة الاستخدام

المنتج النهائي يجب أن يوفّر PWA (تطبيق ويب قابل للتثبيت) عربية أولاً، ويمكن فتحها من Safari/Chrome وإضافتها إلى الشاشة الرئيسية.

## ما يجب أن يكون ممكناً من الهاتف

- إنشاء Agent (وكيل).
- تعديل Instructions (التعليمات).
- اختيار Model Policy (سياسة النموذج).
- إضافة Tool (أداة).
- ضبط Permissions (الصلاحيات).
- إنشاء Workflow (سير عمل).
- تشغيل وإيقاف Agent.
- مراجعة Logs (السجلات).
- الموافقة أو الرفض للأفعال الحساسة.
- رفع ملفات المعرفة.
- إدارة Teams (فرق الوكلاء).
- مراجعة Evals (التقييمات).
- إدارة Deployments (عمليات النشر والتشغيل).

## ما لا يجب أن يكون شرطاً على المستخدم

- Terminal (سطر أوامر).
- VS Code Desktop (في إس كود للحاسوب).
- Docker محلي.
- Python محلي.
- Node.js محلي.
- جهاز Linux شخصي.

## بيئة التطوير الحالية

أثناء بناء المشروع يمكن استعمال GitHub Codespaces (بيئة تطوير غيت هب السحابية) وGitHub Actions (عمليات غيت هب الآلية) من الموارد المتاحة، لكن الاستخدام النهائي للمصنع لا يجب أن يتطلب من المستخدم معرفة هذه الأدوات.

## مبادئ UX (تجربة المستخدم)

- Arabic First (العربية أولاً).
- الأسماء التقنية الإنجليزية تظهر مع معناها العربي عند الحاجة.
- أزرار كبيرة مناسبة للهاتف.
- لا جداول معقدة في الشاشات الرئيسية.
- Wizard (معالج خطوات) لإنشاء الوكيل.
- Advanced Mode (وضع متقدم) منفصل للمستخدم الخبير.
- إشعار واضح قبل أي فعل حساس.

## معيار القبول

Phone-Only Mode (وضع الهاتف فقط) لا يُعتبر ناجحاً حتى يستطيع المستخدم إنشاء Agent وتشغيله ومراجعة نتيجته من الهاتف دون كتابة أمر واحد في Terminal (سطر الأوامر).
