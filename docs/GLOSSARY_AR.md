# Glossary (المعجم التقني العربي)

## قاعدة واجهة المستخدم

الواجهة النهائية تكون عربية أساساً. المصطلح الإنجليزي يظهر عندما يفيد المستخدم تقنياً، وبالصيغة:

`Workflow (سير العمل)`

وليس بإجبار المستخدم على التعامل مع واجهة إنجليزية كاملة.
